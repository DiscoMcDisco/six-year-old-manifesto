# Design Constitution

## Purpose

The purpose of the Six-Year-Old Manifesto interface is not to attract attention. It is to help people distinguish between evidence, possibility, uncertainty and opinion.

The interface should make the work easier to understand, inspect, question and reuse. It must never compete with the ideas it presents.

## Constitutional principles

### 1. Colour communicates meaning, never identity

The Manifesto has no brand colour.

Colour is reserved for semantic use. Every coloured element must communicate a defined state of knowledge, capability, uncertainty or concern. If removing a colour does not reduce understanding, that colour is decorative and should normally be removed.

### 2. Every visual element should answer a question

A visual element must help the reader understand structure, evidence, status, relationship, sequence or action.

Decoration is not forbidden, but it must never obscure meaning, imitate certainty or consume attention that belongs to the evidence.

### 3. The interface should disappear behind the evidence

People should leave remembering the question, the evidence and the implications, not the visual performance of the website.

Typography, spacing, motion and composition should support calm reading and comparison. Technological theatre, ornamental complexity and attention-seeking effects are out of character.

### 4. Certainty must never be exaggerated

The interface must not visually present an estimate as a fact, an emerging capability as a proven one, or an unknown as an empty space to be quietly ignored.

Confidence, limitations, source quality and unresolved questions should be visible wherever they materially affect interpretation.

### 5. Unknown is a legitimate result

The Manifesto treats an honest lack of knowledge as useful information.

Unknown, untested and not-yet-investigated states must be represented deliberately rather than folded into failure, hidden in footnotes or replaced with optimistic inference.

### 6. Accessibility is part of meaning

Meaning must not depend on colour alone.

Every semantic state must also be conveyed through text, labels, symbols, position, pattern or structure. The interface must remain understandable in monochrome, under common forms of colour-vision deficiency, in print and through assistive technology.

### 7. A child should be able to follow the logic

The system should be internally consistent enough that a six-year-old can begin to infer what it means without first learning a brand manual.

This does not require childish presentation. It requires plain language, stable conventions and visible cause and effect.

### 8. Restraint is a form of honesty

The interface should avoid gradients, glow, glass effects, animated colour and unnecessary motion where they do not add information.

Emphasis must be earned. The strongest visual treatment should belong to the most important meaning, not the most marketable claim.

### 9. The design must survive the website

The visual grammar should work across web pages, PDFs, presentations, reports, charts, diagrams, print, data exports and future interfaces.

The underlying semantics must remain stable even when the medium, layout or exact colour values change.

### 10. The evidence may change; the rules for showing it should not change casually

The Manifesto is a living body of work. Findings will develop, classifications may be revised and new evidence will arrive.

Changes to the visual grammar should therefore be treated as governed decisions. They must not be made merely to freshen the appearance or imitate a current design trend.

## Governing test

Before introducing or retaining any visual treatment, ask:

1. What does it mean?
2. Is that meaning already conveyed more clearly elsewhere?
3. Does it exaggerate certainty or importance?
4. Does it still work without colour?
5. Will the same rule make sense in another medium?

If those questions cannot be answered, the treatment should not enter the canonical design language.
